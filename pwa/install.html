One APEX. On your phone, tablet or desktop. Install directly from your browser with your team's colours and favourite features.

Open this page in Safari, Chrome or Edge. If an install button is unavailable, follow the steps for your device below.

Android

  1. Open your deployed APEX address in Chrome.
  2. Tap the browser menu ⋮, then Install app or Add to Home screen.
  3. Confirm and open APEX from your launcher.

iPhone & iPad

  1. Open your deployed APEX address in Safari.
  2. Tap Share → Add to Home Screen. If missing, check Edit Actions.
  3. Enable Open as Web App if offered, then tap Add.

Windows

  1. Open APEX in Microsoft Edge or Chrome.
  2. Use the address-bar install icon, or the browser menu's Apps / Install this site as an app option.
  3. Launch APEX from Start. Pin it to your taskbar if you like.

macOS

  1. Open APEX in Safari on macOS Sonoma 14 or later.
  2. Choose File → Add to Dock or Share → Add to Dock, then confirm.
  3. Or use Chrome's address-bar install icon.

APEX is an installable web app. Internet access is required for the dashboard, historical library and feeds. When disconnected, it shows a connection screen. There are no native APK, IPA, EXE or DMG downloads in this release.

Team and spoiler preferences are saved on this device. An installed app may use separate storage from your browser. Google sign-in is optional and requires the host's OAuth configuration.
